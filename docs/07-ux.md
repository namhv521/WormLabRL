# SPEC-07 — Web UX, interaction flows & visual states

## 1. Product UX goals

Tạo web demo để người chơi hiểu **game**, thấy **AI thực sự thử giải**, và nhận diện rõ sự khác nhau giữa **RL policy** với **BFS verified solver**. Ưu tiên khả dụng trên desktop và điện thoại.

## 2. Information architecture

| Màn | Path dự kiến | Nội dung |
|---|---|---|
| **Play** | `/play` | Chọn tier, board, move, restart, new map, success banner |
| **Watch AI** | `/lab` | Chọn level, RL model/BFS, replay từng bước, outcome/steps |
| **Experiments** | `/experiments` | Metrics Easy/Medium/Hard, run/model IDs, seeds, baselines |
| **About / Rules** | `/about` | Luật, giới hạn hỗ trợ, giải thích độ khó thuật toán |

## 3. Core flow — Play

1. Mở `/play` → chọn `Easy | Medium | Hard` (mặc định Easy).
2. Nhấn `Generate verified level`; UI hiện loading và request `/levels/generate`.
3. Nếu thành công: board rendered theo state, hiển thị `Level ID`, tier, apples left, moves used/max, nhãn `Verified solvable`.
4. Dùng `↑ ↓ ← →` hoặc `WASD`; mobile có D-pad bốn nút. Web gửi action cho session API, chờ response authoritative.
5. Move invalid: animation rung cell/feedback `Blocked move`, step_count vẫn tăng, không đổi hình học.
6. Win: overlay `Solved in N moves`, nút `Try next level` và `Replay` (replay human path P1; MVP dùng Restart).
7. Hết bước/khóa hoàn toàn: overlay `Attempt ended`, CTA `Restart` hoặc `Watch solution`.

## 4. Core flow — Watch AI

1. Người dùng chọn `RL agent` (và model ID) hoặc `BFS verified solution`.
2. Khi bấm `Run`: backend trả action list + outcome, UI dùng engine-authoritative session/replay state để dựng animation.
3. Có control `Play/Pause`, `Step`, `Restart replay`, speed `0.5× | 1× | 2×` (speed chỉ là UI animation, không tác động kết quả tính toán).
4. Dòng kết quả hiển thị `Solved / Failed / Timeout`, number of moves, agent name, optional optimality gap (chỉ khi cả hai giải thành công).
5. Với RL fail, hiển thị **`RL could not solve this level`**; gợi ý xem BFS bên dưới, tuyệt đối không gộp hai action lists thành một kết quả RL.
6. Với BFS, hiển thị `Verified shortest path` chỉ khi certificate và ruleset version khớp.

## 5. Core flow — Experiment dashboard

- Bộ lọc `model_id`, `training_seed`, `tier`, `dataset_version`.
- Bar/table success `RL / Random / Greedy / BFS` kèm `solved/total`, không chỉ %.
- Tóm tắt `mean success over 3 seeds` và từng seed run; không dùng mock numbers trên production dashboard.
- Chỉ số `average steps when solved`, `timeout count`, `unavailable bands`, training steps.
- Nếu data trống: `No completed evaluation for this model` với link hướng dẫn chạy CLI.

## 6. UI states & error handling

| Trạng thái | Feedback |
|---|---|
| Loading level | `Finding a certified level...`, spinner, disable Generate để tránh double submit |
| `LEVEL_POOL_EMPTY` | `No verified level available at this tier yet`, CTA chọn tier khác hoặc thử lại |
| `INVALID_ACTION` schema | UI programming error, log request_id, không thay đổi state local |
| Blocked legal-enum move | Nhẹ nhàng báo `Move blocked`, tăng step count theo response |
| `SESSION_EXPIRED` | `Session expired`, CTA start again; không giữ board state làm như còn sync |
| `MODEL_INCOMPATIBLE` | `This model does not support this ruleset`, chọn model khác |
| `INFERENCE_TIMEOUT` | `Model attempt timed out`, cho phép retry hoặc xem BFS |
| Failed RL | `Not solved by this model`, không gọi là map unsolvable |
| Win | Nổi bật thành tích moves, CTA next/restart |

## 7. Accessibility & responsive behavior

- Bản board cell tỉ lệ vuông; trên màn 360px có D-pad ở dưới board, không cần swipe phức tạp.
- Hướng di chuyển được mô tả bằng icon + aria-label; nút có focus visible; công tắc màu có text.
- Khi mode Play active, keyboard arrows/WASD không gây scroll trang; khi focus vào form/input thì giữ hành vi nhập bình thường.
- Không phụ thuộc vào màu đỏ/xanh để phân biệt tường, táo, exit; dùng biểu tượng tương phản và text alt.
- `prefers-reduced-motion`: tắt animation move hoặc speed minimal, vẫn xem được từng bước.

## 8. Microcopy & định nghĩa minh bạch

- **Verified solvable** = đã có đường đi từ solver được replay xác minh.
- **AI success rate** = model RL hoàn thành bao nhiêu episode trên tập chưa train.
- **Algorithmic difficulty** = điểm dựa trên số bước tối ưu và effort BFS; không phải xếp hạng người chơi.
- **New level** = một level do hệ thống chọn/sinh, không bảo đảm vô hạn map độc nhất trên board hữu hạn.

## 9. MVP acceptance

- Điều khiển keyboard và touch tối thiểu 4 hướng; tile states rõ ràng.
- UI luôn dùng `state` từ backend sau action; không âm thầm tự áp dụng gameplay logic để tăng responsiveness.
- Xem được RL fail độc lập với BFS success, model và ruleset hiển thị rõ.
- `LEVEL_POOL_EMPTY`, session expired và endpoint error có UI state xử lý, không crash/blank.
- Dữ liệu dashboard không có thì empty state, không hiển thị chỉ số mock.
